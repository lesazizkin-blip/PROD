## Как начать (каждому, 15 минут, первым делом)
1. Склонировать: `git clone https://gitlab.t-education.com/hack-led-20/prod_1.git MoverMate` (свой токен GitLab с `read_repository` и `write_repository`).
2. **Своё имя в git:** `git config user.name "Имя Фамилия"` и `git config user.email "<почта>"` в папке проекта.
3. Запустить локально: `scripts/run-site.sh` (сайт и API на :8000) или для разработки — раздел «Быстрый старт» в `README.md`.
4. Своя ветка от свежего `master`: `git switch -c <фамилия>/<задача>` (например `ryabinin/unpack-queue`).
5. Отправка с открытием MR: `git push -o merge_request.create -o merge_request.target=master origin HEAD`. Пайплайн MR зелёный → Merge → сайт выкатится сам.
6. Ветки короткие: больше 2 часов без MR — разбить задачу.

## Новые эндпоинты (контракт, Бэкенд 2 переносит в `API.md` в первый час)
Фронтенд начинает по этому контракту, не дожидаясь сервера.

| Эндпоинт | Ответ | Для чего |
|---|---|---|
| поле `first_night: bool` у коробки (`POST/PATCH …/boxes`, в ответе Box) | — | пометка «нужна в первый вечер», миграция `0005` |
| `GET /api/projects/{pid}/first-evening` | `{ "checklist": [FirstDayItem], "boxes": [Box] }` — пункты первого дня и коробки с `first_night`, по номеру | экран «Первый вечер» |
| `GET /api/projects/{pid}/unpack-queue` | `[Box]` со статусом `delivered`: сначала `first_night`, затем по комнате, затем по номеру | очередь распаковки |

Для экрана погрузки новый эндпоинт **не нужен**: коробки комнаты отдаёт `GET …/boxes?room=<комната>&page_size=200`, массовая отметка — `POST …/boxes/bulk-transitions` (атомарно, `409` с номерами).
