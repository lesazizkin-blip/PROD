# Полный путь переезда: от решения до «обжились»

MoverMate ведёт переезд по семи этапам. Что из этого уже в сервисе и где:

| Этап | Что делает сервис | Где |
|---|---|---|
| 1. Решение | Калькулятор: коробки, объём, машина, грузчики, часы, бюджет «от–до», срок подготовки, советы по дате. Работает без входа, ничего не сохраняет; смету можно перенести в бюджет проекта | `/calculator`, `POST /api/calculator`, `backend/app/services/calculator.py` |
| 2. Новое жильё | План «Снимаю или сдаю квартиру»: осмотр, фото «до», счётчики, подъезд для грузовика, акт, залог | Умный чек-лист → `renting` |
| 3. Подготовка | Персональный ИИ-план с уточняющими вопросами; планы «Документы и смена адреса», «Разобрать вещи до упаковки», дети, питомцы, другой город | Умный чек-лист, `/projects/plan-questions` |
| 4. Подрядчики | Пока вне сервиса: смета из калькулятора — основа заказа | — |
| 5. Упаковка | Коробки, опись по фото, раскладка комнаты по фото, QR-этикетки, поиск, первый день | «Коробки», «QR-этикетки» |
| 6. День переезда | Погрузка и приёмка по номерам: «погружено 34 из 40», что осталось, чего не хватает; повреждения — статус вещи | `/moving-day` |
| 7. Обжиться | План «Обжиться после переезда»; итог переезда: задачи, доехавшие и распакованные коробки, потери, бюджет | «Прогресс» → «Итог переезда» |
| Сквозное | Бюджет «план–факт» по статьям с отклонением | `/budget`, `GET/POST/PATCH/DELETE /api/projects/{pid}/expenses` |

Калькулятор — ориентир: коэффициенты (цены грузчиков, машины, коробок, уборки) в начале
`calculator.py`, их легко поправить. Бюджет хранится в таблице `expenses` (миграция `0008_expenses`).
Тесты: `backend/tests/test_journey.py`, `frontend/src/features/journey/journey.test.tsx`, шаги в `scripts/e2e/ui_click.py`.

Дальше по концепции (не сделано): маркетплейс подрядчиков, страхование груза по описи, напоминания в Telegram,
фото повреждений, бюрократия с шаблонами заявлений, разбор вещей «продать/отдать» с выгрузкой на площадки.
