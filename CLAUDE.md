## Что построено (всё работает локально и на ВМ)
Сервис: проект переезда → план задач на 3 этапа → коробки с номерами и комнатами → вещи (быстрый ввод) → статусы (собирается, собрана, погружена, доставлена, распакована) → поиск вещи → QR-этикетки, печать, сканер → прогресс по комнатам → потерянные вещи с подсказками, напоминания, чек-лист первого дня, умный чек-лист на правилах.

| Часть | Где | Стек |
|---|---|---|
| Сервер | `backend/app` (роутеры → сервисы → модели), 51 эндпоинтов | FastAPI, SQLAlchemy, Alembic, SQLite (в Docker-томе) |
| Сайт | `frontend/src` (pages, components, state, api, ui) | React 19, Vite, TypeScript, обычный CSS, react-router |
| Образ | `Dockerfile` в корне (сайт + сервер в одном) | `STATIC_DIR` — сервер сам отдаёт сайт |
| ВМ-деплой | `deploy/docker-compose.yml`, `deploy/Caddyfile` | Caddy с автоматическим HTTPS + контейнер app |
| Проверка | `scripts/preflight.sh <адрес>` | полный сценарий ТЗ на временном проекте |

**Тесты:** сервер 88 (+1 пропущен: параллельность только на PostgreSQL), покрытие 98% (`cd backend && .venv/bin/python -m pytest --cov=app`); сайт 61 (`cd frontend && npm test`). Линтеры чистые.

## Как запускать
```bash
scripts/run-site.sh                 # сайт и API на http://localhost:8000 (сам ставит окружение, нужен Python 3)
cd backend && .venv/bin/alembic upgrade head && .venv/bin/python -m app.seed   # миграции и демо-проект
cd frontend && npm run dev          # разработка: 5173, /api проксируется на :8000
scripts/preflight.sh <адрес>        # проверка стека (локально, на ВМ)
```
Демо-проект: фиксированный id `00000000-0000-4000-8000-000000000001`, владелец — демо-аккаунт `demo` (`python -m app.seed`; `--load` добавляет нагрузочный: 300 коробок, 3000 вещей).

## Грабли, на которые уже наступили
- **zsh не разбивает переменную на слова:** `SSH="ssh -i ..."; $SSH` не работает. Используй функцию `vm() { ssh -i ~/.ssh/vm1.pem ... "$@"; }`.
- **Кириллица в пути (`ПРОЕКТЫ`) ломает CocoaPods** (iOS-сборка): собирали копию с латинским путём.
- **`run_in_terminal` принимает только ASCII в команде**; путь с кириллицей передавай через параметр `cwd`.
- **Chrome с режимом «только HTTPS»** показывает ошибку на `http://`; поэтому поставили Caddy.
- Тесты запускаются из `backend/` (миграционный тест читает `alembic.ini` по относительному пути).
- Закрывай лишние вкладки Terminal: лимит 6 вкладок на сессию.
- `git` раньше требовал принять лицензию Xcode (принята); если снова пишет про лицензию, `DEVELOPER_DIR=/Library/Developer/CommandLineTools git ...`.
- Тесты и скрипты берут окружение из `backend/.venv` (в репозиторий не входит).
