# MoverMate: переезд без хаоса

Кейс №1 хакатона PROD (Т-Банк, ЦУ, ВШЭ), команда 20. Сервис ведёт переезд от решения до «мы обжились»: план задач, коробки с номерами и комнатами, вещи, статусы, QR-этикетки, поиск вещи за секунды и прогресс по комнатам.

- **Живой сайт:** https://hack-led-20-vm1-12902f.vmaas-spirit.t-education.com (Swagger: `/api/docs`)
- **Демо:** «Войти» → логин `demo`, пароль `demo-pereezd`. Демо-проект «Переезд на Лесную» общий для всех, кто входит в демо. Гость видит «О нас», «Путь переезда» и «Вопросы».
- **Вход:** логин и пароль, без почты и телефона. Проект видят только участники: владелец и те, кого он пригласил ссылкой.

## Что умеет сервис
- **Минимум ТЗ:** проект → план задач на три этапа (стандартный из 14 задач со сроками от даты переезда или пустой) → коробки (номер, комната, вещи списком) → статусы коробки (собирается, собрана, погружена, доставлена, распакована: вперёд по порядку, назад — на любой этап без причины) → статус вещи → поиск вещи → QR-этикетки, печать, сканер → прогресс по комнатам → потерянные вещи с подсказками, напоминания, первый день, памятка.
- **Сверх минимума** (`docs/FEATURES.md`): путь переезда из 7 этапов, калькулятор и бюджет «план–факт», умный чек-лист на правилах, ИИ по согласию (план с уточняющими вопросами, опись коробки и раскладка комнаты по фото), компактные QR и шаблоны этикеток, помощники по ссылке-приглашению.

## Стек
| Часть | Где | Технологии |
|---|---|---|
| Сервер | `backend/app` (роутеры → сервисы → модели) | FastAPI, SQLAlchemy, Alembic, SQLite |
| Сайт | `frontend/src` (pages, components, features, state, api, ui) | React 19, Vite, TypeScript, react-router |
| Образ | `Dockerfile` в корне | сайт и сервер в одном образе (`STATIC_DIR`) |
| Деплой | `deploy/` | Docker Compose, Caddy с автоматическим HTTPS |

## Быстрый старт
Нужны Python 3 и Node.js.
```bash
scripts/run-site.sh   # сайт и API на http://localhost:8000 (сам ставит окружение)
```
Для разработки:
```bash
cd backend && python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt -c constraints.txt
cd backend && .venv/bin/alembic upgrade head && .venv/bin/python -m app.seed   # миграции и демо-проект (--load: 300 коробок, 3000 вещей)
cd backend && .venv/bin/uvicorn app.main:app --reload                          # API на :8000
cd frontend && npm install && npm run dev                                      # сайт на :5173, /api проксируется на :8000
```

## Тесты и проверки
```bash
cd backend && .venv/bin/python -m pytest --cov=app        # 241 тест (+2 пропущены: параллельность — на PostgreSQL в CI, аннотации — на Python 3.14), покрытие 98%
cd frontend && npm test && npm run lint && npm run build  # 209 тестов; npm run test:ci — с покрытием
scripts/preflight.sh <адрес>                              # сценарий ТЗ на запущенном сайте
scripts/e2e.sh                                            # прод по API + локально права, приглашения и проклик интерфейса
```
Тесты сервера запускать из `backend/` (миграционный тест читает `alembic.ini` по относительному пути).

## Деплой
